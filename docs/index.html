Markmap Plus

Preview your markdown as an interactive mind map in VS Code.

Install from VS Code Marketplace Source on GitHub

Getting started

Open a Markdown file and run Markmap Plus: Open as markmap from the Command Palette. You can also use the editor title-bar button or the file context menu. See the full README for usage and configuration.

Keyboard shortcuts

Available while the preview has focus. Press ? in the preview to see them.

KeyAction
FFit window size
EExpand all
CCollapse all
+ / =Zoom in
-Zoom out
/Search nodes
?Show/hide the shortcut help

Folding nodes

In the preview, left-click a branch node to toggle its immediate children; right-click it to toggle the entire subtree. Ctrl/Cmd+click also toggles the whole subtree. Links and areas outside branch nodes keep their context menus.

When the Markdown editor is active, use the Command Palette's Markmap Plus: Toggle the active node or Markmap Plus: Toggle the active node recursively to act on the node at the text cursor. Neither command has a default keybinding, so typing t or r edits the text normally. You can assign your own keybindings in VS Code.

Search

Press / to search the map. Paths to matches stay open and other branches fold. If there are no matches, the previous fold state remains visible. Enter jumps to the next match, Shift+Enter to the previous one, and Esc clears the search and restores the fold state you had before.

Fold state

Fold state is remembered per file in the current VS Code workspace. Editing node content can change its identity and prevent that node's saved state from being restored. Open previews of the same document synchronize folding.

Export

Use the Export button in the toolbar to save the map as SVG, PNG or a HTML page. HTML includes the viewer but does not embed local images or apply extension settings; document frontmatter still applies. Remote resources require network access. Markdown exports the branches that are currently open as a nested list.

Configuration

{
  "markmapPlus.defaultOptions": "{ \"colorFreezeLevel\": 2 }",
  "markmapPlus.customCSS": "markmap-view { --mm-link: rebeccapurple; }",
  "markmapPlus.theme": "cards",
  "markmapPlus.layout": "org-chart"
}

markmapPlus.theme takes classic, cards or minimal; markmapPlus.layout takes tree, two-sided or org-chart. Leave either empty to use the document's frontmatter, or the default. After clearing a previously selected theme or layout, reopen the preview to restore the document's value. Default options and custom CSS do not apply to exported HTML; custom CSS cannot reach inside the map.

Migrating from markmap-vscode

  1. Install Markmap Plus (cgxiao.markmap-plus).
  2. Optionally disable markmap-vscode (gera2ld.markmap-vscode) to avoid duplicate commands and editor choices.
  3. Copy your settings to the new keys.
    Old key New key
    markmap.defaultOptions markmapPlus.defaultOptions
    markmap.customCSS markmapPlus.customCSS

Markmap Plus builds on Gerald's markmap-vscode and adds features such as preview shortcuts, node search, and Markdown outline export. It uses markmap to render mind maps.

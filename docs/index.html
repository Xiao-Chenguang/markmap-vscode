Migrating from markmap-vscode

  1. Uninstall or disable the original markmap-vscode. Both register a markdown custom editor, so keeping both installed leads to unpredictable behaviour.
  2. Install Markmap Plus.
  3. Rename your settings — the keys changed so the two extensions can coexist:
    Old key New key
    markmap.defaultOptions markmapPlus.defaultOptions
    markmap.customCSS markmapPlus.customCSS

Keyboard shortcuts

Available while the preview has focus. Press ? in the preview to see them.

KeyAction
FFit window size
EExpand all
CCollapse all
+ / =Zoom in
-Zoom out
TToggle the node under the cursor
RToggle the node under the cursor recursively
/Search nodes
?Show/hide the shortcut help

Search

Press / to search the map. Matching branches stay open and everything else folds away, so a large document collapses to just the parts that match. Enter jumps to the next match, Shift+Enter to the previous one, and Esc clears the search and restores the fold state you had before.

Fold state

The branches you fold are remembered per file, so reopening a document shows the map the way you left it. Node ids are content hashes, so renaming a heading simply drops that node from the saved state instead of breaking it.
